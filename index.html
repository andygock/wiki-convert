About WikiConvert

Supported markup, privacy, shortcuts, and limitations.

Supported conversions

Common rich-text structures recognised by the converter

  • Headings from level 1 through level 6
  • Bold, italic, underline, strikethrough, and inline code
  • Ordered, unordered, and nested lists
  • Tables with header and data cells
  • Hyperlinks, block quotations, and preformatted text
  • Paragraphs and explicit line breaks
  • Microsoft Word list and heading metadata

Privacy

All processing occurs on the current device

Pasted and dropped content is processed entirely by JavaScript running in this browser. The application does not submit content to a server or third-party conversion service.

Input, output, and settings remain in memory only for the current tab and are discarded when it closes or reloads.

Keyboard shortcuts

Common actions available from the converter view

Convert content Ctrl + Enter
Copy MediaWiki output Ctrl + Shift + C
Focus rich-text input Ctrl + Shift + V

Limitations

Content requiring manual review

  • Embedded images are represented by descriptive comments.
  • Complex Word drawings and SmartArt cannot be reconstructed.
  • Tracked changes and comments may be flattened by the browser.
  • Highly customised table layouts may require manual adjustment.
